# 💊 Drug Inventory Management System

A full-stack web application designed to simplify drug inventory management through
secure authentication, inventory tracking, REST APIs, and data visualization.

## 🚀 Features

- 🔐 JWT-based user authentication
- 📦 Drug inventory management
- 📊 Interactive dashboard and data visualization
- 🔎 Inventory information and tracking
- 🔄 RESTful API-based backend
- 🗄️ MongoDB database integration
- 🌐 Responsive web interface

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JSON Web Tokens (JWT)

### Visualization
- Chart.js
